## 说明

开发版拨到开发版优先时持有命名互斥量，正式版每 2 秒探测一次，在就让出同一组资源，不在就拿回；开发版退出或崩溃时内核自动回收，正式版自愈。普通用户机器上互斥量永远不存在，这段代码不起作用。审批服务现在绑定后停不下来（监听线程永不退出），要改成可停止、可重新绑定，这样 47830 才能真的换手（Claude Code 的钩子地址里端口是安装时写死的）。这一步改的是正式版的行为，随下个版本发布后才对安装版生效。

## 验收

- 开发版优先：release 构建放掉快捷键、系统键、39271 和 47830，开发版接管，审批请求到开发版。
- 杀掉开发版进程后，release 构建几秒内自己拿回全部资源。
- 没有开发版在跑时，release 构建的行为和现在完全一样。
- 审批服务的停止和重绑有单元测试。
