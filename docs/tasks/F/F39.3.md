## 说明

调试构建默认就是 `com.tixxin.fuyu.lane-1`，要用正式身份时设 `FUYU_DEV_SHARED_IDENTITY=1`。`stop-running-island.mjs` 默认只停本仓库 `target/debug` 里的进程。首次启动把正式数据目录复制过来（旧的 lane 数据改名保留），排除锁文件、数据目录指针、`home-migration.json`（带着它会把 Agent 钩子重新指向开发版目录）、审批和本地接口的端口配置、钩子脚本和钩子产物；QQ、微信、邮件提醒的开关不带过来。Agent 钩子写的状态文件，开发版只读地从正式数据目录读。

## 验收

- 不带任何环境变量跑 `pnpm tauri dev`，安装的正式版不退出，两个岛同时在。
- 首次启动后开发版里有正式版的待办、设置和插件；`~/.claude/settings.json` 和 `~/.codex/config.toml` 的钩子没有被改。
- 开发版能看到 Agent 的「等你确认」这类状态。
- `FUYU_DEV_SHARED_IDENTITY=1` 时行为和改动前的 `pnpm tauri dev` 一样。
- 文档（AGENTS.md、workflow.md、data-home.md、contracts.md、platforms.md）同步，Mac 上的会话收到通知。
